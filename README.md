# Maternal diet and genetics shape the human milk metabolome

Code and supporting resources accompanying the manuscript:

> **Johnson KE, et al.**
> *Maternal diet and genetics shape the human milk metabolome.*

---

## Overview

This repository contains the analysis code used to generate the results presented in the manuscript, including statistical analyses, genome-wide association studies, machine learning models, and publication figures.

The study integrates human milk metabolomics with maternal dietary, transcriptomic, genomic, and clinical data to identify maternal factors influencing variation in the human milk metabolome.
